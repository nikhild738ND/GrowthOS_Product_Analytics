## Dashboard 3 — Customer Retention and Repeat Purchase

Analyzes anonymous-user purchase status, repeat-purchase behavior,
time to first purchase, and weekly activity retention cohorts.

## Dashboard 4 — Product Opportunity and Experiment Priority

Prioritizes high-traffic products with below-category descriptive
performance using configurable traffic and gap-recovery assumptions.

## Interpretation limitations

GA4 user_pseudo_id represents a pseudonymous identifier and should not
be interpreted as a verified person across browsers or devices.

Cohort retention represents return activity, not necessarily repeat
purchase.

Product opportunity is a scenario estimate rather than a forecast
or causal result.
